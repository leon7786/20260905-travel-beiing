# 2026 北京出发自驾大环线 · 数字化导航地图与路书

> 🌐 **在线交互地图 (GitHub Pages)**: [https://leon7786.github.io/20260905-travel-beiing/](https://leon7786.github.io/20260905-travel-beiing/)  
> 🏞️ **核心景区与风貌图鉴**: [https://leon7786.github.io/20260905-travel-beiing/attractions.html](https://leon7786.github.io/20260905-travel-beiing/attractions.html)

基于高精度中国地理坐标构建的北境自驾数字化路书，适配 PC、iPad（横竖屏）、iPhone、Android 等各种移动与桌面设备，支持路线一键切换、全景同屏比选、动态轨迹回放、多省核心景区多维筛选与纯净浅色地图导航。

---

## 🗺️ 包含页面与模块

1. **路线地图导航 (`index.html`)**：
   - 方案一：15天 关外山海与边境线（约 2,000 km）
   - 方案二：16天 草原森林与地质奇观大环线（约 2,200 km）
   - 方案三：15天 关东名胜 + 华北圣山跨省大环线（约 2,700 km）
   - 多路线全景对比、轨迹漫游回放、高德标准/开源OSM/极简浅灰/高清卫星底图切换。

2. **核心景区与风貌图鉴 (`attractions.html`)**：
   - 完整收录河北、辽宁、内蒙古、京津/吉林、山东/山西 5 大区域 20 大核心风景名胜区；
   - 支持按省份地域、生态地貌类型标签进行实时筛选搜索；
   - 提供「在地图中查看」直达定位功能。

## 💻 目录结构

- `index.html`：数字化自驾路线交互地图导航
- `attractions.html`：20 大核心风景名胜与地貌图鉴大全
- `.nojekyll`：保障 GitHub Pages 极速直出加载
- `plan/`：
  - `0.txt`：环线设计哲学、选线逻辑与季节出游建议
  - `1.txt`：方案一逐日行程数据表
  - `2.txt`：方案二逐日行程数据表
  - `3.txt`：方案三逐日行程数据表
  - `spots.csv`：20 大核心景区、关联子景点与风景类型结构化数据表
