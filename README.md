# 2026 北京出发自驾大环线 · 数字化导航地图与路书

> 🌐 **在线交互地图 (GitHub Pages)**: [https://leon7786.github.io/20260905-travel-beiing/](https://leon7786.github.io/20260905-travel-beiing/)

基于 Leaflet 与高精度中国地理坐标构建的北境自驾数字化路书，支持多路线一键切换、全景同屏对比、动态轨迹回放、景点信息检索与卫星/暗色地图图层切换。

---

## 🗺️ 包含路线方案

### 方案一：15天 关外山海与边境线（约 2,000 km）
* **特色**：关外盛京历史、辽东边境风情、海滨漫步与雄关要塞。
* **主要途经**：北京 ➔ 金山岭长城 ➔ 承德避暑山庄 ➔ 锦州医巫闾山 ➔ 兴城古城 ➔ 盘锦红海滩 ➔ 鞍山千山 ➔ 本溪水洞 ➔ 丹东鸭绿江断桥/虎山长城 ➔ 沈阳故宫/大帅府 ➔ 棋盘山 ➔ 秦皇岛山海关/老龙头/北戴河 ➔ 天津蓟州盘山 ➔ 北京。

### 方案二：16天 草原森林与地质奇观大环线（约 2,200 km）
* **特色**：地貌景观极其丰富，兼收塞罕坝浩瀚林海、乌兰布统丘陵草甸、阿斯哈图冰川石林与太行白石山绝壁栈道。
* **主要途经**：北京 ➔ 承德 ➔ 围场塞罕坝 ➔ 乌兰布统草原 ➔ 赤峰阿斯哈图石林 ➔ 锦州医巫闾山 ➔ 笔架山/红海滩 ➔ 鞍山千山 ➔ 本溪水洞 ➔ 沈阳 ➔ 兴城 ➔ 秦皇岛 ➔ 蓟州盘山 ➔ 保定涞源白石山 ➔ 北京。

### 方案三：15天 关东名胜 + 华北圣山跨省大环线（约 2,700 km）
* **特色**：深度融入华北人文历史与五岳禅宗，串联东北名城后南切太行与齐鲁平原。
* **主要途经**：北京 ➔ 承德 ➔ 秦皇岛 ➔ 辽沈边境（沈阳、丹东） ➔ 蓟州盘山 ➔ 涞源白石山 ➔ **忻州五台山**（佛教圣地深度游） ➔ **泰安泰山**（登五岳独尊） ➔ 德州 ➔ 北京。
